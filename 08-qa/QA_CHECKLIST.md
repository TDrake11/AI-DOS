# QA Checklist

## Functional

- authentication,
- authorization,
- ownership,
- CRUD,
- validation,
- error handling,
- pagination/filter/search,
- file upload,
- external integrations.

## UI

- desktop,
- tablet,
- mobile,
- loading,
- empty,
- error,
- retry,
- keyboard,
- visual consistency.

## Non-functional

- performance,
- security,
- logging,
- monitoring,
- backup/restore,
- migration,
- accessibility.
