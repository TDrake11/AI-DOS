# Coding Standards

- Tuân theo style hiện tại của repository.
- Ưu tiên type safety.
- Không dùng `any` không cần thiết.
- Không nuốt exception.
- Không log secret hoặc dữ liệu nhạy cảm.
- Function và class có trách nhiệm rõ.
- Tránh duplicate logic.
- Tên biến và API phải rõ nghĩa.
- Comment giải thích lý do, không lặp lại code.
- Xử lý null, empty và failure paths.
- Không để TODO/FIXME mới nếu chưa ghi Technical Debt.
