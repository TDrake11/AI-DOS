# Performance Rules

- Đo trước khi tối ưu lớn.
- Phân trang danh sách lớn.
- Resize và nén ảnh.
- Lazy load nội dung ngoài màn hình.
- Tránh tải dữ liệu không cần thiết.
- Dùng cache khi tính nhất quán cho phép.
- Tối ưu query và index.
- Tránh bundle frontend quá lớn.
- Kiểm tra mobile performance.
- Không hy sinh tính đúng đắn hoặc bảo mật để lấy điểm benchmark.
