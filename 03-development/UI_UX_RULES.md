# UI/UX Rules

## Mục tiêu

- thống nhất,
- rõ ràng,
- responsive,
- accessible,
- dùng được trên production data.

## Trước khi tạo UI

1. Tìm component tương tự.
2. Kiểm tra design system hiện tại.
3. Tái sử dụng token, button, modal, card, table, form.
4. Không tạo phong cách riêng lẻ cho từng trang.

## Trạng thái bắt buộc khi phù hợp

- loading,
- skeleton,
- empty,
- error,
- retry,
- success,
- disabled,
- confirmation cho hành động nguy hiểm.

## Responsive

Kiểm tra tối thiểu:

- mobile nhỏ,
- mobile lớn,
- tablet,
- desktop.

## Accessibility

- semantic HTML,
- keyboard navigation,
- focus state,
- label,
- contrast,
- aria khi cần.
