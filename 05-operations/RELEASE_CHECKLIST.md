# Release Checklist

- [ ] All tasks DONE or valid Manual Actions only.
- [ ] No critical risk unresolved.
- [ ] Build and tests pass.
- [ ] Database migrations verified.
- [ ] Security checks completed.
- [ ] Smoke test production passed.
- [ ] Regression test passed.
- [ ] UAT completed or exceptions documented.
- [ ] Manual Action Queue reviewed.
- [ ] Technical Debt updated.
- [ ] Changelog updated.
- [ ] Rollback plan available.
- [ ] Release tag/version created if workflow requires.
