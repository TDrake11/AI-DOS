# Bugfix Prompt

```text
Read the project manifest and run conformance before debugging. Inspect the
real issue and related code, reproduce it safely, identify root cause, add a
regression test, and implement the smallest maintainable fix. Apply only the
rules and quality gates selected by the project execution profile. Record
structured evidence, update canonical state, and use the repository Git
policy. If human-only access is required, add a precise Manual Action and
continue independent work.
```
